Ticket 001 - Restablecimiento de contraseña
Incidencia
Usuario no puede iniciar sesión porque ha olvidado la contraseña.Entorno
Windows Server 2022
Active Directory
Diagnóstico
Se verifica que la cuenta existe.
No se observan bloqueos.
El usuario confirma que ha olvidado la contraseña.
Resolución
Buscar usuario en Active Directory.
Restablecer contraseña.
Forzar cambio de contraseña en el siguiente inicio de sesión.
Resultado
Usuario accede correctamente al sistema.
